# ASP.NET Web Forms Application

A C# ASP.NET Web Forms project demonstrating server-side web development, `.aspx` UI markup, code-behind event handling, and application configuration.

## Tech Stack

- **Framework:** ASP.NET Web Forms (.NET Framework)
- **Language:** C#, HTML5, CSS3
- **IDE:** Visual Studio

## How to Run

1. Clone or download the repository.
2. Open the `.sln` solution file in **Visual Studio**.
3. Restore NuGet packages if prompted (`Build` > `Rebuild Solution`), then press `F5` to launch in your browser.
